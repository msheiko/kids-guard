# KidGuard: установка и приёмка

Служба Windows для родительского контроля доступа к ПК с управлением через Telegram-бота.
Спецификация — [SPEC-telegram.md](../SPEC-telegram.md).

## 1. Что понадобится

- ПК ребёнка с Windows 10 22H2 x64 (Home или Pro) или Windows 11.
- Учётная запись **родителя** — администратор с паролем.
- Учётная запись **ребёнка** — **локальная стандартная** (не администратор). Учётные записи Microsoft в v1 не поддерживаются.
- Исходящий доступ в интернет к `api.telegram.org` (HTTPS, порт 443). Входящие соединения не нужны.
- Telegram у каждого родителя.
- Для сборки — .NET 10 SDK (на ПК ребёнка SDK не нужен: программа собирается в самодостаточные exe).

## 2. Подготовка ПК

1. Проверьте, что у ребёнка стандартная учётная запись: «Параметры → Учётные записи → Семья и другие пользователи»
   (тип «Стандартный пользователь»). Если ребёнок — администратор, KidGuard не установится.
2. Задайте пароль администратора родителю и не сообщайте его ребёнку.
3. Поставьте пароль на BIOS/UEFI и отключите загрузку с USB/DVD. Без этого ребёнок может загрузить другую ОС
   или перевести часы в BIOS (см. «Ограничения»).

## 3. Создание бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Задайте имя (например, «KidGuard дом») и username, оканчивающийся на `bot` (например, `ivanov_kidguard_bot`).
3. BotFather пришлёт **токен** вида `123456789:AA…`. Это главный секрет: кто знает токен, может управлять ботом.
   Никому его не пересылайте.
4. Рекомендуется запретить добавлять бота в группы: `/setjoingroups` → выберите бота → `Disable`.
   Бот всё равно игнорирует группы и выходит из них.

## 4. Сборка

На любом компьютере с Windows и .NET 10 SDK, в папке с исходным кодом:

```powershell
powershell -ExecutionPolicy Bypass -File .\publish.ps1
```

Скрипт прогоняет тесты и кладёт в папку `publish\` два файла: `KidGuard.Service.exe` и `KidGuard.Tray.exe`.
Скопируйте оба на ПК ребёнка (например, на флешке) в одну папку.

## 5. Установка

На ПК ребёнка войдите под **родителем**, откройте «Командную строку» **от имени администратора**, перейдите в папку
с файлами и выполните:

```
KidGuard.Service.exe install --user kid --token 123456789:AA... --device-name kid-pc
```

Параметры:

| Параметр | Описание |
|---|---|
| `--user` | Имя локальной учётной записи ребёнка (как в `net user`) |
| `--token` | Токен бота от @BotFather |
| `--device-name` | Имя ПК в сообщениях бота (по умолчанию — имя компьютера) |
| `--time-zone` | Часовой пояс службы, Windows ID (по умолчанию — текущий пояс Windows). Список: `tzutil /l` |
| `--proxy` | Прокси для Telegram: `http://host:port` или `socks5://host:port`, можно с `user:password@` |
| `--safe-mode` | Запускать службу и в безопасном режиме Windows |

Что делает установка:

1. Проверяет, что учётная запись ребёнка существует и не входит в «Администраторы», и проверяет токен в Telegram.
   Если что-то не так — **ничего не меняет**.
2. Копирует программу в `C:\Program Files\KidGuard\` (ребёнок может только читать и запускать).
3. Создаёт `C:\ProgramData\KidGuard\` с доступом только для SYSTEM и администраторов и пишет `config.json`
   (токен шифруется DPAPI).
4. Отзывает у группы «Пользователи» права менять часовой пояс и системное время.
5. Регистрирует службу `KidGuard` (автозапуск, перезапуск через 5 секунд при сбое, остановить может только администратор)
   и запускает её.
6. Выводит **одноразовый код привязки** и имя бота.

Повторный запуск `install` обновляет программу и настройки, привязанные родители сохраняются.

## 6. Привязка родителей

1. Откройте бота (по username из вывода установки) и отправьте `/start 123456` с кодом из вывода. Код действует 10 минут.
   Бот ответит «Вы привязаны как родитель» и пришлёт панель управления.
2. Второй родитель: первый родитель отправляет боту `/invite` (или администратор выполняет на ПК
   `KidGuard.Service.exe pair`) и пересылает код. Второй родитель отправляет боту `/start <код>`.
3. Удалить родителя: `/parents` → «Удалить». Последнего родителя удалить нельзя.

Бот отвечает только привязанным родителям. Остальным он ничего не отвечает (кроме сообщения о неверном коде
привязки), а родителям не чаще раза в час приходит уведомление о попытке доступа.

## 7. Управление через бота

Панель (`/status`) показывает доступ, сеанс, время за сегодня, расписание и лимит сеанса. Кнопки панели:
выключить или включить доступ, `+15 / +30 / +60`, завершить сеанс, сообщение ребёнку, лимит сеанса, расписание, настройки.

Команды:

| Команда | Пример |
|---|---|
| Включить / выключить доступ | `/on`, `/off` (`/off now` — без минуты на сохранение работы) |
| Продлить сеанс | `/add 30` |
| Завершить сеанс, не меняя доступ | `/end` |
| Лимит сеанса | `/limit 60`, `/limit off` |
| Дневной лимит | `/daily будни 120`, `/daily выходные 240`, `/daily пн 90`, `/daily off` |
| Расписание | `/schedule будни 16:00-20:00`, `/schedule сб,вс 10:00-13:00,15:00-21:00`, `/schedule вс нет`, `/schedule on` |
| Разрешить вне расписания | `/allow 30` |
| Сообщение ребёнку | `/msg Пора ужинать` |
| Отчёты | `/today`, `/week` |
| Уведомления, родители | `/notify`, `/parents`, `/invite` |

Режим после лимита сеанса (кнопка «Лимит сеанса»): **блокировать** — доступ выключается до ручного включения;
**перерыв** — вход запрещён на `cooldown_minutes`; **ничего** — можно сразу войти снова.

Если ПК был выключен или без сети, команды придут при включении. Последняя команда каждого вида (вкл/выкл, лимиты,
расписание) применяется независимо от давности; разовые действия (`+N`, `/end`, `/allow`, `/msg`, ответы на запросы
времени) старше 10 минут не выполняются. Родителям приходит сводка.

## 8. Тонкая настройка (`config.json`)

Файл `C:\ProgramData\KidGuard\config.json` доступен только администратору. Откройте Блокнот **от имени администратора**,
измените параметры и перезапустите службу (командная строка от имени администратора):

```
sc stop KidGuard
sc start KidGuard
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `warnings_minutes` | `[5, 1]` | За сколько минут предупреждать ребёнка |
| `access_off_grace_seconds` | `60` | Время на сохранение работы при выключении доступа (0 — сразу) |
| `session_merge_minutes` | `10` | Выход и вход в течение этого времени продолжают прежний сеанс |
| `cooldown_minutes` | `60` | Длина перерыва в режиме «перерыв» |
| `count_sleep` | `false` | Засчитывать ли время сна и гибернации |
| `offline_policy` | `keep_last` | `keep_last` — без связи всё работает как было; `lock_after` — см. ниже |
| `offline_lock_minutes` | `15` | Для `lock_after`: через сколько минут без связи во время сеанса завершать его |
| `time_request_min_interval_minutes` | `5` | Минимальный интервал между запросами времени |
| `stale_command_minutes` | `10` | С какого возраста разовые команды считаются устаревшими |

Часовой пояс и токен меняются только через CLI (раздел 9). Токен, список родителей и имя бота в файле менять вручную не нужно.

### Обход через отключение сети

Ребёнок может отключить Wi-Fi, чтобы до ПК не дошла команда «выключить доступ». Лимиты, расписание и таймер при этом
всё равно работают — они считаются на ПК. Если важно, чтобы без связи с родителями ПК нельзя было использовать,
задайте `"offline_policy": "lock_after"`: если связи с Telegram нет дольше `offline_lock_minutes` во время сеанса,
сеанс завершится, а вход будет запрещён до восстановления связи. При появлении сети родители получат уведомление.

## 9. Обслуживание (CLI)

Все команды — в командной строке от имени администратора:

| Команда | Описание |
|---|---|
| `KidGuard.Service.exe status` | Состояние службы, связи, доступа, сеанса и лимитов |
| `KidGuard.Service.exe unlock` | Аварийно включить учётную запись ребёнка и доступ, без Telegram |
| `KidGuard.Service.exe unlock --allow 60` | То же и разрешить вход вне расписания на 60 минут |
| `KidGuard.Service.exe pair` | Новый код привязки родителя |
| `KidGuard.Service.exe set-token <токен>` | Заменить токен (если утёк: в @BotFather `/revoke`, затем эта команда) |
| `KidGuard.Service.exe set-time-zone "Belarus Standard Time"` | Сменить часовой пояс службы |
| `KidGuard.Service.exe uninstall` | Удалить службу, включить учётную запись ребёнка, вернуть права (`--keep-data` — оставить данные, `--yes` — без вопроса) |

Журналы: `C:\ProgramData\KidGuard\logs\` (хранятся 14 дней) и «Просмотр событий → Журналы Windows → Приложение»,
источник `KidGuard` (только ошибки). Токен в журналы не пишется.

## 10. Ограничения

- KidGuard не защищает от пользователя с правами администратора, загрузки другой ОС и переустановки Windows —
  для этого нужны стандартная учётная запись ребёнка и пароль на BIOS/UEFI.
- Если перевести часы вперёд в BIOS при выключенном ПК и без сети, это обнаружится только при появлении сети
  (по времени серверов Telegram). Закрывается паролем на BIOS.
- Когда ПК выключен или без сети, бот не отвечает. Команды, отправленные в это время, Telegram хранит до 24 часов.
- У нажатий кнопок в Telegram нет даты отправки. Нажатия, пришедшие сразу после перерыва связи дольше 10 минут,
  считаются отправленными в начале перерыва.
- Без `--safe-mode` служба не запускается в безопасном режиме. Вход в безопасный режим ребёнку закрывают
  пароль администратора и BIOS.
- Предупреждения ребёнку — всплывающие уведомления Windows. Если включён режим «Не беспокоить», они могут
  не показываться, но сеанс всё равно завершится вовремя.

## 11. Чек-лист ручной приёмки

Сценарии из раздела 14 спецификации. Отмеченные «тесты» проверяются автоматически (`dotnet test`), но их стоит
один раз пройти и на реальном ПК. Пункты «вручную» проверяются только на ПК.

Подготовка: установите KidGuard, привяжите двух родителей (два аккаунта Telegram), войдите на ПК под ребёнком.

| № | Как проверить | Ожидается | Проверка |
|---|---|---|---|
| 1 | Ребёнок за ПК. В панели «Выключить доступ» → «Да» | Подтверждение в боте; у ребёнка уведомление «Родитель выключил доступ…»; через 60 с выход; `net user kid` — «Учётная запись активна: Нет» | вручную |
| 2 | `/on` | Ребёнок может войти (если позволяют расписание и дневной лимит) | тесты, вручную |
| 3 | `/limit 30`, ребёнок входит | Уведомления на 25-й и 29-й минуте, выход на 30-й | тесты |
| 4 | `/limit 60`, на 25-й минуте `/limit 20` | Выход через 1 минуту | тесты |
| 5 | `/limit 30`, на 28-й минуте `+15` | Выход на 45-й минуте | тесты |
| 6 | Режим «блокировать», дождаться конца лимита | Доступ выключен, уведомление родителям | тесты, вручную |
| 7 | Режим «перерыв» | Вход запрещён 60 минут, затем разрешён | тесты |
| 8 | Выйти на 10-й минуте, войти через 3 минуты | Сеанс продолжается с 10-й минуты (`/status`) | тесты, вручную |
| 9 | Расписание 16:00–20:00, вход в 19:50, лимит 60 | Предупреждения в 19:55 и 19:59, выход в 20:00 | тесты |
| 10 | Дневной лимит 120, использовано 110, лимит сеанса 60 | Выход через 10 минут | тесты |
| 11 | `/allow 30` в 21:00 при расписании до 20:00 | Вход возможен до 21:30 | тесты |
| 12 | `/limit 30`, ребёнок входит, на 5-й минуте отключить сеть (кабель / Wi-Fi) | Выход на 30-й минуте без сети | вручную |
| 13 | `offline_policy = lock_after`, во время сеанса отключить сеть | Через 15 минут выход и блокировка; при подключении — уведомление, вход снова разрешён | тесты, вручную |
| 14 | Выключить ПК; в боте `/off`, затем `+30`; включить ПК | Доступ выключен, на `+30` ответ «устарела», обоим родителям сводка | тесты, вручную |
| 15 | У ребёнка: значок KidGuard → «Попросить ещё времени» | Обоим родителям сообщение с кнопками; после «+30» у одного у второго «Обработано: +30 мин (…)», у ребёнка «Время добавлено» | тесты, вручную |
| 16 | Повторить запрос через минуту | «Следующий запрос можно отправить через …» | тесты |
| 17 | Написать боту с третьего аккаунта | Бот молчит, родителям уведомление (не чаще раза в час) | тесты, вручную |
| 18 | `/start 000000` с третьего аккаунта; код старше 10 минут | «Код неверный или устарел» | тесты |
| 19 | Под ребёнком: Диспетчер задач → завершить `KidGuard.Tray` | Через ≤ 30 с значок появляется снова; выход по лимиту происходит вовремя | вручную |
| 20 | Под ребёнком: `sc stop KidGuard`; открыть `C:\ProgramData\KidGuard\config.json`; подключиться к службе через «Службы» | «Отказано в доступе» во всех случаях | вручную |
| 21 | `/limit 30`, перезагрузить ПК на 10-й минуте, войти в течение 10 минут | Сеанс продолжается; старые команды из Telegram повторно не выполняются | тесты, вручную |
| 22 | `/limit 30`, усыпить ПК на 2 часа на 10-й минуте | Сон не засчитан, выход через 20 минут после пробуждения | тесты, вручную |
| 23 | `install --user <администратор> ...` | Ошибка, ничего не изменено | вручную |
| 24 | `uninstall` | Службы нет (`sc query KidGuard`), учётная запись ребёнка включена | вручную |
| 25 | Отключить сеть, доступ выключен; `unlock` | Ребёнок может войти | вручную |
| 26 | Администратором сменить часовой пояс Windows с +3 на −2 в 21:00 при расписании до 20:00 | Вход по-прежнему запрещён, учёт за день не сброшен, родителям уведомление | тесты, вручную |
| 27 | Под ребёнком: «Параметры → Время и язык» → сменить часовой пояс | Windows не даёт сменить (нет права) | вручную |
| 28 | Администратором перевести системное время на 3 часа вперёд | Уведомление о скачке; расписание считается по доверенному времени | тесты, вручную |
| 29 | Выключить ПК, в BIOS откатить дату на день, загрузить без сети | Используется последнее доверенное время, учёт не сброшен; при появлении сети — уведомление | тесты, вручную |
| 30 | Системное время расходится со временем Telegram на 10 минут | Используется поправка, уведомление | тесты |
| 31 | Отключить сеть на 40 минут во время сеанса | После подключения — уведомление с длительностью офлайна и сеанса; офлайн виден в `/today` | тесты, вручную |

## 12. Если что-то не работает

- **Бот не отвечает.** `KidGuard.Service.exe status`: служба работает? Есть ли связь с Telegram? Посмотрите журнал
  в `C:\ProgramData\KidGuard\logs\`. Если Telegram заблокирован — переустановите с `--proxy`.
- **«Cannot decrypt bot token».** Выполните `set-token <токен>`.
- **Служба постоянно перезапускается.** В журнале событий «Приложение» будет причина: нет учётной записи ребёнка,
  она стала администратором или повреждён `config.json`.
- **Нет значка у ребёнка.** Проверьте, что `KidGuard.Tray.exe` лежит в `C:\Program Files\KidGuard\`
  рядом с `KidGuard.Service.exe`. Контроль работает и без значка, но без предупреждений.
- **Ребёнок не может войти, а Telegram недоступен.** `KidGuard.Service.exe unlock` (или `unlock --allow 60`).
